# Project workflow

- After completing requested website changes, run the relevant checks, commit the completed work, and push it to the configured remote. The user expects completed changes to be pushed, not left only in the local checkout.
- Honor any later instruction to keep particular work local or uncommitted.
- Preserve unrelated user changes. Do not force-push or rewrite shared history.
- Report the pushed branch and commit, and distinguish a successful Git push from a verified deployment.
